# F013 — Conformance fixture plan titles read "Plan for P00"

Status: closed

Severity: low

Location:
conformance/valid/{basic,cancelled,completed,draft,implemented,in-progress,verified}/.plan/P001/plan.md
conformance/invalid/{dependency-cycle,duplicate-plan-id,duplicate-task-id,incomplete-dod,invalid-plan-status,invalid-task-status,missing-dependency,missing-plan-reference,planner-owned-task,unauthorized-verification,verified-without-verification,wrong-location,draft-plan-implementation}/.plan/P001/plan.md

## Observation

The conformance fixture Plan records use the heading `# P001 — Plan for P00` (and the
`duplicate-plan-id` fixture's `P001a/plan.md` similarly). The title "Plan for P00" is
a typo for the Plan ID `P001`. It does not affect validation but is an inconsistency
with the Plan ID in the heading and is likely to mislead readers of the fixtures.

## Recommendation

Correct the fixture titles to `Plan for P001`.

## Decision

Status: accepted

Rationale:
Fix fixture titles to `# P001 — Plan for P001` (and `P001a`).

## Verification

Status: verified

Evidence:
- No conformance fixture Plan record contains the "Plan for P00" title.
- `conformance/invalid/duplicate-plan-id/.plan/P001a/plan.md:1` reads `# P001 — Plan for P001` (corrected from P00).

Checks performed:
- `grep -rn "Plan for P00" conformance/` → no matches (exit code 1).
- `grep -c "Plan for P001" conformance/valid/basic/.plan/P001/plan.md` → 1.

## Implementation

Status: implemented

Changes:
- Conformance fixture plan titles corrected from `Plan for P00` to `Plan for P001` (including `P001a`).
