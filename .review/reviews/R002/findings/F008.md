# F008 — §8 lifecycle diagram shows Cancelled only from Planned, contradicting the transition table

Status: closed

Severity: low

Location:
SPEC.md §8 (diagram, lines 306–309)
SPEC.md §8.5 (transition table, line 360)

## Observation

The §8 lifecycle diagram shows `Cancelled` branching only from `Planned`:

```text
Draft → Planned → Completed
              ↘ Cancelled
```

but the §8.5 transition table permits `any → Cancelled` (including `Draft →
Cancelled` and `Completed → Cancelled`). The diagram understates the legal
transitions and is inconsistent with the normative table.

## Recommendation

Update the §8 diagram to reflect the table (for example note that `Cancelled` may be
reached from any state), or clarify that the diagram is illustrative.

## Decision

Status: accepted

Rationale:
Update §8 diagram to note `Cancelled` is reachable from any state.

## Verification

Status: verified

Evidence:
- `SPEC.md:302` lifecycle diagram now includes `Cancelled (reachable from any state)`.

Checks performed:
- `grep -n "Cancelled" SPEC.md` → diagram line 302 notes "reachable from any state", consistent with the §8.5 `any → Cancelled` transition.

## Implementation

Status: implemented

Changes:
