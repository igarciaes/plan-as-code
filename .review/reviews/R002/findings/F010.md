# F010 — README minimum repository structure shows the old flat layout

Status: closed

Severity: low

Location:
README.md (lines 87–96)

## Observation

The "What is the minimum repository structure?" block still shows the retired flat
layout:

```text
.plan/
├── README.md
├── plans/
│   └── P001.md
└── tasks/
    └── P001-T001.md
```

SPEC §5 defines the v0.5.0 default layout as one directory per Plan
(`.plan/<PlanID>/plan.md` and `.plan/<PlanID>/tasks/<TaskID>.md`). The README minimum
layout contradicts the normative default layout.

## Recommendation

Update the README minimum-layout block to the per-plan layout defined in SPEC §5.

## Decision

Status: accepted

Rationale:
Update README minimum-structure block (lines 87–96) to the per-plan layout.

## Verification

Status: verified

Evidence:
- `README.md` minimum-structure block now shows the per-plan layout:
  ```text
  .plan/
  ├── README.md
  └── P001/
      ├── plan.md
      └── tasks/
          └── P001-T001.md
  ```

Checks performed:

## Implementation
