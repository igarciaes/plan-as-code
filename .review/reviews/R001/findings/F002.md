# F002 — Invalid relationship combinations not machine-checked

Status: open

Severity: low

Location:
SPEC.md (§23.2)
tools/validate.py

## Observation

SPEC.md §23.2 normatively requires relationships to be validated for "invalid relationship combinations" (for example a task both `depends-on` and `conflicts-with` the same target) and states that detection is machine-checkable (Section 28). `tools/validate.py` implements INV-005 (missing targets) and INV-006 (cycles) but no check for invalid combinations.

## Recommendation

Add a machine-checkable invariant (or extend INV-005/INV-006) that detects contradictory relationship combinations on the same task.

## Decision

Status: accepted

Rationale:
A typed relationship representation (`**Relationships:**`) will be added to SPEC.md, the validator, the schema, tests, and conformance fixtures so invalid relationship combinations are machine-checkable.
